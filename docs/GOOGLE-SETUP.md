# HandyTranslator Google · 개인용 시제품 v0.3

2026-11-16. Google Cloud Translation을 사용하는 Android 9+ 개인용 앱이다.

- 설치: `deliverables/HandyTranslator-Google-v0.3.apk` (기존 Google 앱 위에 업데이트 설치)
- 새 소스: `google-app/` · 패키지 `com.handytranslator.google`
- **보드 펌웨어와 D4/D5 배선은 바꿀 필요가 없다.**

## v0.3 화면

- 기본 화면: 상태, 시작/종료, 두 방향 누르고 말하기, 최근 번역문, 설정.
- 설정: 보드 자동 시작, API 키 저장/삭제, 사용량, 테스트, 음성/배터리 설정, 사용 안내.
- API 키 입력과 테스트는 기본 화면의 `설정`으로 이동한다. 기존 키·사용량·자동 시작 설정을 유지한다.
- 크기는 dp, 글자는 sp 기준이며 넓은 화면에서는 본문 너비를 최대 600dp로 제한하고 중앙에 배치한다. 세로·가로 및 작은 창에서는 스크롤한다. 버튼 높이는 최소값만 지정하고 텍스트에 따라 늘어난다.
- 시스템 바·화면 잘림 영역의 여백과 키보드 표시 영역에 대응한다. 화면 회전 후 설정 페이지 여부도 유지한다. 입력 중인 미저장 API 키는 보관하지 않는다.
- 아래 기존 설정 절차의 세션 시작/종료는 기본 화면의 `시작`/`종료`, 문장/화면 꺼짐 테스트는 `설정 → 테스트`에 해당한다.

## 구성과 화면 꺼짐

물리 버튼 → Android 기본 SpeechRecognizer → Google Cloud Translation Basic v2 NMT → Android 오프라인 TTS.

화면을 켠 상태에서 사용자가 마이크 권한을 허용하고 세션을 시작한 뒤, 전원 버튼으로 화면을 꺼도 서비스에서 MIDI·음성인식·번역·읽기를 처리하도록 구현했다. 앱은 화면을 깨우거나 켜짐을 유지하지 않는다. 마이크 포그라운드 서비스 알림과 시스템의 마이크 사용 표시를 숨기지 않는다.

세션 중 PARTIAL_WAKE_LOCK으로 CPU 동작을 요청한다. 화면 절전은 가능하지만 전력 소비가 0이 되는 것은 아니다. 세션은 최대 2시간이며 알림 또는 앱의 종료 버튼으로 끝낸다. 종료 시 MIDI·인식기·TTS·wake lock을 정리한다. 화면이 꺼진 상태의 장시간 대기와 네트워크는 Doze 및 제조사 절전 정책의 영향을 받으므로 기기 검증이 필요하다.

**v0.2는 USB 연결에 의한 앱 열기 및 세션 자동 시작을 추가했다.** 최초 연결 시 Android의 앱 선택 창에서 HandyTranslator Google을 선택하고, 표시되는 경우 항상 사용/기본 사용을 지정한다. 앱의 `보드 연결 시 번역 세션 자동 시작`은 기본으로 켜져 있다.

앱 화면이 활성화되고 화면 잠금이 해제된 뒤, API 키와 마이크 권한이 준비된 경우에만 자동 시작한다. 잠긴 상태에서 최초 연결한 경우에는 잠금 해제나 앱 선택이 필요할 수 있다. 이미 실행 중인 세션은 재연결로 재시작하지 않는다. 세션 종료 후 단순히 앱으로 돌아오는 것으로는 다시 시작하지 않으며, 새 연결 또는 수동 시작이 필요하다. 자동 시작은 대기 상태만 준비하고, 물리 버튼을 누르기 전에는 녹음하지 않는다.

필터는 제공한 Leonardo 펌웨어의 실행 모드 VID/PID `2341:8036`, `2A03:8036`에 한정한다. 연결된 장치와 MIDI 인터페이스도 확인하고, 버튼 신호는 기존 펌웨어 핸드셰이크를 거쳐 받는다. 자동 시작 스위치를 꺼도 Android가 USB 기본 앱을 열 수 있다. 앱 열기까지 끄려면 Android의 기본 앱/USB 연결 기본 설정을 해제한다. 화면을 강제로 끄거나 잠금을 해제하는 기능은 없다.

## 1. Google Cloud 준비

1. [Google Cloud 콘솔](https://console.cloud.google.com/)에 로그인한다.
2. 프로젝트 선택 → 새 프로젝트. 예: `handytranslator-personal`. 이 프로젝트를 번역 전용으로 사용한다.
3. 결제 계정을 만들거나 기존 결제 계정에 프로젝트를 연결한다. **무료 사용 범위에서도 결제 연결이 필요하다.** 가입 과정에 표시되는 결제 수단·조건은 본인이 확인한다.
4. API 및 서비스 → 라이브러리 → **Cloud Translation API** 검색 → 사용 설정.
5. 이 앱에는 Cloud Speech-to-Text, Cloud Text-to-Speech, Vertex AI, Gemini API를 활성화할 필요가 없다.

공식 문서: [초기 설정](https://docs.cloud.google.com/translate/docs/setup), [가격](https://cloud.google.com/products/translate/pricing).

## 2. 무료 범위와 사용량 제한

공식 가격 기준 NMT 텍스트 번역은 월 첫 **500,000 문자에 $10 크레딧**이 적용된다. Basic/Advanced의 해당 사용량을 합산하며 크레딧은 청구 계정 단위로 적용된다. 초과분은 표준 가격 기준 100만 문자당 $20이다. 무료 체험의 일회성 크레딧과는 다르다. LLM·문서·다른 Cloud 서비스에는 같은 무료 조건을 가정하지 않는다.

무료 한도를 넘으면 자동으로 무료 모드로 멈추는 상품이 아니므로, 먼저 할당량을 낮춘다.

1. Cloud 콘솔에서 번역 프로젝트를 선택한다.
2. API 및 서비스 → Cloud Translation API → **할당량 및 시스템 한도**에서 일일 문자 할당량(Characters per day)을 찾는다.
3. 프로젝트 전체 일일 문자 한도를 **14,000**으로 낮춘다. 31일 사용해도 434,000 문자다. 분당 한도와 혼동하지 않는다. 콘솔에서 변경 적용 여부를 확인한다.
4. 결제 → 예산 및 알림에서 프로젝트를 대상으로 작은 예산 알림도 설정한다. **예산 알림 자체는 과금 차단 기능이 아니다.**
5. 같은 결제 계정의 다른 번역 프로젝트가 무료 크레딧을 사용하지 않는지 확인한다. 프로젝트 하나의 할당량으로 계정 전체의 과금을 보장할 수는 없다.

앱도 요청 전에 일 14,000 / 월 450,000 / 한 번 3,000 문자 상한을 검사한다. Unicode 코드 포인트로 세며 실패·시간초과도 보수적으로 요청량에 남긴다. 자동 재시도하지 않는다. 미국 태평양 날짜 기준으로 일/월을 구분한다. **이 값은 폰 한 대의 추정 요청량이며 Google 청구 내역이 아니다.** 앱 삭제·데이터 초기화, 다른 폰·앱·프로젝트, 기기 날짜 변경에는 완전한 보호가 되지 않는다. Cloud 콘솔 제한이 필요하다.

공식 문서: [번역 할당량](https://docs.cloud.google.com/translate/quotas).

## 3. API 키 만들기

1. API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → **API 키**.
2. 키 편집 → **API 제한** → 키 제한 → **Cloud Translation API만 선택**한다.
3. 애플리케이션 제한 → **Android 앱**. 다음 패키지와 SHA-1 인증서 지문을 등록한다.

```text
패키지: com.handytranslator.google
SHA-1: 60:F2:85:F5:CD:9D:40:C2:9A:DC:0A:45:7A:F2:92:93:A8:E5:9D:78
```

위 지문은 함께 제공하는 v0.3 APK용이다. 다른 서명 키로 빌드했다면 해당 APK의 지문을 사용한다. 앱은 요청에 패키지·인증서 헤더를 보낸다. 키 제한 적용은 실제 API 호출로 확인해야 하며, 403 오류가 나면 제한·API 활성화·결제·할당량을 확인한다. 무작정 모든 제한을 풀지 않는다.

4. 앱의 키 입력란에 **폰에서 직접 입력**하고 `API 키 암호화 저장`을 누른다. 이 채팅, 소스 파일, 스크린샷으로 키를 보내지 않는다.
5. 키는 Android Keystore의 AES-GCM 키로 암호화하여 앱 전용 저장소에 저장한다. 키 입력 화면은 캡처를 막고, 저장 후 키를 다시 표시하지 않는다. APK에 키를 포함하지 않으며 앱 백업을 비활성화했다.

모바일에 키를 보관하는 개인 시제품이다. 앱 제한 헤더만으로 유출된 키의 악용을 완전히 방지할 수는 없다. 타인에게 배포하는 제품은 중계 서버 인증 구조로 전환한다. 키 유출 시 Cloud 콘솔에서 폐기·재발급한다.

공식 문서: [API 키 제한](https://docs.cloud.google.com/api-keys/docs/add-restrictions-api-keys).

## 4. 폰 설정과 사용

1. 폰에서 USB host/OTG와 기본 음성인식 서비스를 사용할 수 있는지 확인한다.
2. Google APK를 설치하고 `HandyTranslator Google`을 연다.
3. 폰의 음성 읽기 설정에서 한국어와 일본어 음성 데이터를 내려받는다. 앱의 `음성 읽기 언어 설정`으로 이동할 수 있다. **네트워크 없이 사용할 수 있는 TTS 음성**이 있어야 한다. 음성 선택·설치 메뉴는 엔진/폰에 따라 다르다.
4. 화면을 켠 상태에서 `번역 세션 시작` → 마이크·알림 권한 허용 → 필요하면 다시 `번역 세션 시작`.
5. 키 없이도 `10초 뒤 화면 꺼짐 음성 테스트`를 누르고 전원 버튼으로 화면을 끄면, 10초 후 일본어 테스트 문장을 읽도록 되어 있다. 이 테스트는 녹음이나 번역 API 요청을 하지 않는다.
6. 키를 저장한 뒤 두 방향의 문장 테스트를 실행한다. API 활성화·인증·읽기가 모두 되는지 먼저 확인한다.
7. 보드를 연결하고 두 버튼을 모두 놓는다. 한→일 버튼을 누르고 **준비 진동 뒤** 한국어로 말한다. 놓으면 일본어로 읽는다. 일→한은 반대로 동작한다.
8. 세션이 실행 중인 상태에서 화면을 끄고 같은 테스트를 반복한다. 읽기가 끝나면 다음 입력을 받는다. USB 분리 시 진행 중 입력/결과 재생을 취소하고, 재연결 후 버튼을 모두 놓아야 다시 받는다.
9. 장시간 화면 꺼짐 테스트에서 중단된다면 앱의 배터리 최적화 설정에서 Google 앱과 음성 서비스에 대한 제조사 제한을 확인한다. 설정 변경은 사용자가 수행한다.
10. 사용 후 앱 또는 알림에서 `세션 종료`.

폰에 연결된 Bluetooth/이어폰이 있다면 시스템 미디어 출력 경로로 읽을 수 있다. 폰 스피커 테스트 때는 해당 장치를 해제하고 미디어 볼륨을 확인한다.

## 구현상 제한과 개인정보

- Android SpeechRecognizer는 기본 인식 제공자를 사용한다. 음성이 해당 제공자에게 전송될 수 있다. Cloud Translation에는 인식된 텍스트를 보낸다. 앱은 대화 음성이나 문장을 파일에 기록하지 않으며, 최근 번역문만 앱 프로세스 메모리에 표시한다.
- 번역 이외의 Cloud 음성 API를 사용하지 않아 해당 Cloud 사용료가 생기지 않는다. 기본 인식 서비스의 이용 조건과 모바일 데이터 요금은 별도다.
- 버튼을 누르는 동안 인식기가 침묵으로 끝나면 재시작한다. 최대 45초이며 재시작 사이에 짧은 음성 누락이 있을 수 있다. 무손실 연속 녹음 방식은 아니다.
- 화면 꺼짐·잠금 상태에서 인식 서비스가 동작하는지, 장시간 대기 후 MIDI가 유지되는지는 실기 확인이 필요하다. Android 9는 최소 SDK 설정이며 전 버전 실기 검증을 뜻하지 않는다.
- 정상 세션 시작은 앱이 보이는 상태에서만 수행한다. 프로세스가 종료되면 자동 녹음 재개하지 않는다.
- TTS는 설치된 오프라인 한국어/일본어 음성을 선택한다. 지원하지 않는 엔진이면 먼저 언어 데이터를 설치하거나 엔진을 바꾼다.

## 빌드와 검사

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File google-app\build.ps1
```

JDK 17, Android SDK platform 35/build-tools 35.0.1 사용. 외부 라이브러리 없이 Java 소스를 컴파일하고 프로토타입 인증서로 서명한다. 서명 키는 `google-app/build/`에만 생성하며 소스 ZIP에 넣지 않는다. 이 디렉터리의 서명 키를 삭제하면 같은 APK의 업데이트 설치와 Cloud Android 앱 제한 지문이 달라진다.

자동 검사: 버튼 중복/동시 누름/재연결, MIDI 분할/리얼타임/SysEx, Unicode 문자 수, 상한 경계, 태평양 날짜/월 경계와 서머타임. APK 서명 및 minSdk 28 확인.

사용자 폰에서 실제 키로 양방향 번역, 화면 꺼짐 음성 출력, 10분 이상 대기 후 입력 및 USB 연결 자동 시작을 확인했다. Android 9 실기, 네트워크 단절/복구 등 남은 항목은 [검증 기록](GOOGLE-TEST.md)을 기준으로 한다.
