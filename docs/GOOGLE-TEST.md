# Google v0.1 / v0.2 / v0.3 검증 기록

2026-11-16

## 완료

- Java 컴파일 및 Android D8 변환 성공, APK 서명 검증 성공.
- 최소 Android API 28, 대상 API 35, 패키지 `com.handytranslator.google` 확인.
- Google Cloud Translation을 직접 호출하며 접근성 서비스에 의존하지 않음.
- 버튼 중복/겹침/동시 누름/재연결 및 MIDI 분할 메시지 테스트 통과.
- Unicode 코드 포인트 수, 사용량 상한, 비정상 수치, 태평양 날짜/월 경계 및 서머타임 테스트 통과.
- `KEEP_SCREEN_ON` 또는 화면 밝기 wake lock을 사용하지 않음. 세션 CPU용 partial wake lock 사용.
- APK에 API 키 미포함. 키 입력은 폰에서 직접 수행하며 Keystore로 암호화 저장.
- Google 앱 구현 과정에서 공통 보드 펌웨어 변경 없음.

## 설치 시도

- ADB 연결 기기: `25010PN30G`.
- Google APK 설치 결과: `INSTALL_FAILED_USER_RESTRICTED: Install canceled by user`.
- 이후 사용자 요청으로 재시도하여 ADB 설치 `Success` 확인, `MainActivity` 실행 완료.

## 사용자 실기 검증 완료 (2026-11-16)

- 사용자가 앱에 API 키 직접 입력 완료.
- 화면을 끈 상태의 음성 출력 테스트 통과 보고.
- Google 세션 시작 및 보드 연결 완료.
- 실제 보드로 화면을 끈 상태에서 한→일·일→한 말하기 → 버튼 놓기 → 번역문 읽기 통과 보고.
- 화면을 끄고 10분 이상 대기한 뒤에도 실제 버튼 번역 동작 통과 보고.
- 위 항목은 사용자가 안내한 1~4단계를 모두 통과했다고 보고한 결과다. 다른 기종·Android 버전에 대한 검증을 의미하지 않는다.

## 남은 검증

- Cloud 콘솔 일일 할당량 및 API 키 Android/서비스 제한의 실제 설정값 확인 (번역 성공만으로 설정 완료를 단정하지 않음).
- 네트워크 단절/복구, Google 버전의 USB 재연결.
- Android 9 실기 및 2시간 세션 자동 종료.

v0.1은 현재 사용자 폰에서 화면 꺼짐 양방향 번역과 10분 이상 대기 후 입력이 확인되었다.

## v0.2 USB 자동 시작 (2026-11-16)

- USB 연결 Activity 필터와 실행 모드 VID/PID 필터 추가. 컴파일된 APK에서도 `2341:8036`, `2A03:8036` 확인.
- 실제 연결 장치 및 MIDI 인터페이스 확인 후, 앱이 활성 상태이고 화면 잠금이 해제된 경우에만 세션 자동 시작.
- API 키/마이크 권한 미설정 시 수동 설정 안내. 기존 실행 세션을 재시작하지 않음.
- 연결 이벤트를 한 번 소비하므로 세션 종료 후 앱 복귀/화면 회전만으로 자동 재시작하지 않도록 구현.
- 빌드, 기존 CoreTest/UsageBudgetTest, APK 서명 검증 통과. v0.1과 서명 지문 동일.
- 사용자 폰에 ADB 업데이트 설치 `Success`. 기존 키/사용량 데이터 유지 방식(`install -r`). 키 내용은 조회하지 않음.
- 사용자에게 안내한 세션 종료 → 홈 화면 → 잠금 해제 상태에서 보드 연결 → 앱 선택(표시되는 경우) → 수동 세션 시작 없이 물리 버튼 번역 → 화면을 끄고 사용 절차에 대해, 사용자가 테스트 완료 및 정상 동작을 보고함(2026-11-16).
- 따라서 현재 사용자 폰에서 보드 연결 자동 시작과 이어지는 버튼 번역 동작을 사용자 실기 통과로 기록한다. Android 선택 창이 실제 표시되었는지 등 개별 UI 세부 결과는 별도로 확인하지 않음.
- 기본 앱 지정 후 반복 재연결, 자동 시작 스위치 해제, 잠금 상태에서의 신규 연결은 별도 검증 필요.

## v0.3 UI 간소화 (2026-11-16)

- 기본 화면을 상태·시작/종료·두 방향 입력·최근 번역·설정으로 축소. API 키, 사용량, 테스트와 안내는 설정 페이지로 이동.
- 버튼과 여백은 dp, 글자는 sp 사용. 내용 높이는 가변이며 페이지 스크롤 지원. 넓은 창에서는 최대 600dp 중앙 배치.
- 화면 회전 시 설정 페이지 유지, USB 자동 시작 이벤트 상태 유지. 기존 번역 서비스·API 클라이언트·MIDI·키 저장·사용량 제한 코드 변경 없음.
- 빌드, CoreTest, UsageBudgetTest, APK 서명 검사 통과. 사용자 폰에 업데이트 설치 Success 및 versionCode=3 / versionName=0.3-prototype 확인, 기본 화면 실행.
- 별도 읽기 전용 Android 36 에뮬레이터에서 동일 APK의 UI 계층/좌표 확인: 320×480dp 세로에서 하단 번역 버튼·설정까지 스크롤 접근; 480×320dp 가로 및 글꼴 200%에서 설정 페이지 유지와 하단 접근; 1600×1200dp에서 본문 600dp 중앙 배치 확인.
- 설정에서 시스템 뒤로가기로 기본 화면 복귀 확인. 검사는 실제 키가 없는 에뮬레이터에서 수행했으며 사용자 폰의 해상도·글꼴 설정은 변경하지 않음.
- API 키 보호용 FLAG_SECURE는 유지. 스크린샷 기반 시각 검사가 아닌 UI 계층과 좌표 검사임. 모든 기종·해상도를 실기 검증한 것은 아님.
- 남은 사용자 확인: 새 UI의 사용감, 실제 버튼 번역 및 보드 자동 시작 회귀 확인.

## Google 전용 정리 (2026-11-16)

- Google Cloud Translation을 단일 번역 경로로 확정하고 루트 사용법/설계 문서를 현재 구현에 맞게 재작성.
- 사용 안내 문구를 정리한 v0.3 APK 재빌드, CoreTest/UsageBudgetTest 및 서명 검사 통과. 번역 및 보드 처리 로직 변경 없음.
- 현재 APK/소스 ZIP/해시를 갱신. 최신 배포본과 공통 펌웨어를 유지.

## v0.3.1 앱 아이콘 (2026-11-16)

- 한·일 글자를 윤곽선 벡터로 구성하고 양방향 화살표 추가. 앱 아이콘과 원형 아이콘에 적용.
- Android 13+ 테마 아이콘용 단색 레이어 제공. Android 9+ 기본 adaptive icon 유지.
- versionCode 4, versionName 0.3.1-prototype. 게시된 v0.3 산출물은 덮어쓰지 않음.
- 빌드·CoreTest·UsageBudgetTest·APK 서명 검사 통과. AAPT에서 아이콘 리소스 포함 확인.
- 연결된 사용자 폰에 업데이트 설치 Success. 다양한 런처의 실제 마스크/테마 표현은 별도 실기 확인 대상.
