# HandyTranslator · 확정 프로젝트 방향

2026-11-16: **Google Cloud Translation Basic v2 NMT를 번역 서비스로 확정한다.** 현재 앱은 Google v0.3.1이며, 이 저장소는 Google 기반 두 버튼 번역기를 개발·유지한다.

## 목표

- Android 9+ 스마트폰과 USB로 연결한 두 개의 물리 버튼.
- 한→일 / 일→한 각각 누르고 말하고, 놓으면 번역문 읽기.
- 인터넷 사용, Google Cloud 무료 범위를 고려한 요청량 제한.
- 활성 세션에서 화면 꺼짐 사용 및 보드 연결 자동 시작.
- 기본 화면의 텍스트와 조작 최소화, 다양한 창 크기와 글꼴 대응.

## 현재 구현

1. Pro Micro 5V/16MHz에서 D4/D5 모멘터리 버튼을 읽는다.
2. USB MIDI 채널 16: 호스트 CC102=42, 보드 CC103=42 핸드셰이크, CC104 버튼 상태 비트마스크.
3. Android 기본 SpeechRecognizer로 인식한다. 준비 진동 후 말하며, 누르는 동안 인식기가 끝나면 재시작한다.
4. 버튼을 놓으면 인식된 문장을 Google Cloud Translation v2에 명시적인 ko/ja 방향과 NMT 모델로 요청한다.
5. 설치된 한국어/일본어 오프라인 TTS 음성으로 결과를 읽는다.

## 동작과 전원

- 동시 누름, 연결 시 이미 눌린 버튼, 중복 신호를 걸러낸다.
- 번역/읽기 중에는 새 입력을 받지 않는다. USB 분리 시 진행 중 입력/재생을 취소한다.
- 마이크·미디어 foreground service 및 알림을 유지한다. 화면을 켜는 wake lock은 사용하지 않는다.
- 세션 중 CPU용 partial wake lock을 사용한다. 전력 절감량은 별도 측정 대상이다.
- 자동 시작은 실제 연결 장치, MIDI 인터페이스, 활성 앱 화면, 잠금 해제, 저장된 키와 마이크 권한을 확인한다.
- 잠금 상태의 최초 시작, 재부팅 후 완전 무조작 시작은 보장하지 않는다.

## 인증과 비용

- 개인용 키를 폰에서 입력하고 Android Keystore로 암호화 저장한다.
- Cloud의 API/Android 앱 제한 및 일일 할당량을 설정한다.
- 앱은 일 14,000 / 월 450,000 / 요청당 3,000 코드 포인트로 제한한다. 실패한 요청도 보수적으로 계산하며 자동 재시도하지 않는다.
- 앱 자체 사용량은 계정 전체 청구량이 아니다. 다른 앱/프로젝트 사용량과 무료 범위 공유 여부는 Cloud 콘솔에서 확인한다.
- 배포용 제품으로 확장하면 서버에서 인증 정보를 관리하는 구조가 필요하다.
